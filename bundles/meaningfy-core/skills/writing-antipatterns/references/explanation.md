# Explanation

**Register signature:** one metaphor, example beside claim, rhythm. **Owning skill:**
`explanatory-writing`.

Pointer table only — full entries live in [`inversion-matrix.md`](inversion-matrix.md). See
[`../SKILL.md`](../SKILL.md) for the unguarded defects (U1–U8), which apply here too.

| Move | Status | Entry |
|------|--------|-------|
| Duplication & cardinality | avoid | [A1](inversion-matrix.md#a1-duplication--cardinality) |
| Agentless construction | avoid | [A2](inversion-matrix.md#a2-agentless-construction) |
| Abstraction with no example | **required** — an unexampled claim can't be checked | [A3](inversion-matrix.md#a3-abstraction-with-no-example-and-persuasion-inside-a-commitment) |
| Label headings | welcome | [A4](inversion-matrix.md#a4-label-headings) |
| Deferred definitions | **required** — define at first use | [A5](inversion-matrix.md#a5-deferred-definitions) |
| Hedging | required as a per-claim marker for contested material | [A6](inversion-matrix.md#a6-hedging) |
| Direct address ("you") | welcome | [A7](inversion-matrix.md#a7-direct-address-you) |
| Dense tables vs prose | **harmful** — nothing accumulates as the reader moves down it | [A8](inversion-matrix.md#a8-dense-tables-in-place-of-prose) |
| Answer/goal first | welcome, but see the precedence rule below | [A9](inversion-matrix.md#a9-answergoal-first) |
| Controlling metaphor | **required** — one, start to finish | [A10](inversion-matrix.md#a10-controlling-metaphor--figurative-material) |
| Premature structure | welcome | [A11](inversion-matrix.md#a11-premature-structure) |
| Options shown, not just the choice | welcome | [A12](inversion-matrix.md#a12-options-shown-not-just-the-choice) |
| Curse of knowledge | **harmful** — must build understanding from an accessible start | [A13](inversion-matrix.md#a13-curse-of-knowledge) |
| Negative framing | avoid | [A14](inversion-matrix.md#a14-negative-framing) |

**Precedence when Explanation competes with Decision** (e.g. an explainer that is also a client
recommendation): structure outranks texture — lead with the answer (A9), then apply the slow-burn
metaphor beneath it. Owned by `explanatory-writing`'s own boundary section; cited, not restated.
