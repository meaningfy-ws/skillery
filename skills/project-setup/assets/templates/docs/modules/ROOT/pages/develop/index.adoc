== Common questions

*Where do I start a new feature?*::
In a shaping session: an EPIC in `openspec/changes/<id>/`. Code comes after the PLAN passes the
clarity gate (the `epic-planning` skill).

*One of our libraries does not do what I need. What now?*::
Stop the task and report it upstream; never work around it here. See <<libraries>>.

*Which checks must pass before a PR?*::
See <<gates>>.

[#gates]
== The gates

The gates every task and every PR must pass. How often each one runs scales with the EPIC's
appetite (the `epic-delivery` skill).

[cols="2,3",options="header"]
|===
|Gate |When
|`make check-all` |After every task and before every PR
|`openspec validate --all --strict` |With every change to `openspec/`
|The clarity gate (≥ 9/10) |Before a PLAN's first task
|===

== Before a PR

* The gates above pass.
* Each commit cites its change and task (the `meaningfy-git-workflow` skill).
* No workaround of one of our libraries.
* The PR targets `<<DEFAULT_BRANCH>>`.
