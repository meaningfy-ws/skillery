# Seed: generic task test profiles (EPIC D)

**Secondary input, never groomed.** Seeded 2026-11-13; parked until A (`test-strategy`) is
delivered. Source: the owner's conversation recorded in `../../test-strategy/inputs/seed.md`.

## Intent

The owner: "we might need some more generic testing skills for generic tasks, such as sales,
linkedin post writing, writing legal contracts". Every activity states how it succeeds and how it
fails before the work (test-strategy's founding principle); this EPIC writes those profiles for
work that is not software, docs or design.

## Candidates raised so far (not decided)

- **Success criteria first**: the brief of a post, an offer or a contract states what a good result
  does for its reader, and what failure looks like, before drafting.
- **Rubrics**: a scored checklist per genre, in the style of the clarity gate.
- **Rule checks**: `rulebook check` already tests an output against the owner's rules with check
  patterns.
- **Adversarial readers**: "opposing counsel" for a contract, "sceptical buyer" for an offer, "a
  stranger scrolling" for a LinkedIn post; a cold reader for anything a stranger must act on.
- Owners to cite, not restate: `contract-practice`, `proposal-writing`, `sales-conversations`,
  `executive-communication`, `writing-antipatterns`, `meaningfy-voice`.
