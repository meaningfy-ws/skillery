# Analytics / BI connections

## What it is

Once an organisation has a shared model of its data (see
[modelling / ontology](semantic-ontology-modelling.md)), the next question is usually: can our
existing reporting tools use it? Analytics / BI connections is the work of wiring the semantic model
into the dashboards, reports, and business-intelligence tools a client's teams already use day to
day, so those tools read from the same shared definitions instead of each report re-deriving its own
version of "revenue" or "active customer."

## The problem it solves

Without this, every dashboard becomes its own island: two reports built by two different teams quote
different numbers for what should be the same figure, and nobody can say with confidence which one
is right, because each was built against its own private understanding of the data, not a shared
one. This service exists to connect those islands back to the mainland: the shared model, so a
client's existing analytics investment (the dashboards people already rely on) gets the benefit of
it, instead of the model and the reporting layer staying two disconnected efforts.
