# Usage report, 2026-11-09

The first page of the series. It is a hand-measured evidence file from the `lean-delivery` EPIC, not
a Langfuse report, so its numbers are not comparable with the later pages. The evidence stays where
it was archived:
[`evidence-skillery-time.md`](../../../../openspec/changes/archive/2026-11-09-lean-delivery/inputs/evidence-skillery-time.md).

**Method.** The 15 most recent Claude Code transcripts of skillery (about 75 h of wall time), 40
`gh run list` runs and 14 days of `git log`. Timestamps are the transcripts', with gaps capped at 30
minutes, so idle time includes breaks. One repository only.

**Headline numbers.**

- Main thread: about 17.9 h waiting for the owner, 6.6 h in tool calls, 3.0 h generating.
- Tools: `make validate` 223 calls, 131 min; CI waits 116 min; `make bundles` 87 calls, 58 min.
- Subagents: 69 `general-purpose` runs (314 min), 8 `implementer` (78 min), 2 `epic-planner`.
- A CI run took 51 to 122 s.

**Conclusion given then.** The machine was not the bottleneck; plan churn, repeated full checks and
one question at a time were. The `lean-delivery` change followed from it.
