The baseline of the `skillery-performance-improvement` EPIC. Produced from Langfuse with the
procedure in `skills/session-retrospective/references/langfuse-report.md`; numbers only.

## Window

2026-11-08T00:00Z to 2026-11-23T00:00Z (the last day partial). All projects on the owner's machine
(skillery, rdf-persistence, mapping-workbench-v2 and other repositories), all run with the skillery bundles
installed. Trace name `Claude Code Turn`. Work mix by appetite and repository: not recorded in this
baseline; later pages state it.

## Floors

Seed analysis, 2026-11-22; not reproducible from the queries.

The smallest context seen in a session or a subagent, a proxy for its starting load (system prompt,
tool definitions, skill listing, bindings, memory, hook output).

- **Main thread: 62 to 88 k** (the 40 busiest sessions; most 67 to 78 k). A session never runs
  below this; 95 % of main-thread calls run above 90 k.
- **Subagents, three floors:** implementer subagents 56 k in one repository and 81 to 84 k in
  another; lighter agent types 32 k. The floor depends on the agent type and the repository, not on
  the task.
- Pieces we control, estimated at four characters a token: `AGENTS.md` and `CLAUDE.md` 3.0 k; global
  `CLAUDE.md` 0.7 k; `MEMORY.md` 0.2 k; two session-start hooks 0.8 k and 1.3 k; the skill listing
  (about 230 skills from over 20 plugins); 15 local MCP servers and about 10 connectors whose
  deferred tool names are listed every session.
- 1,124 subagent spawns at about 80 k is about 90 M tokens of cache writes at start alone, two
  thirds of all 5-minute cache writes.

**Owed.** The composition of the floor by the CLI's `/context` command, and the three `implementer`
variants of task 1.4, are to be measured in an interactive session and entered here.

## Cost

The baseline window is uncosted in Langfuse and reads $0. The project had no model prices: its
managed definitions stop at Claude 3.5. Task 1.1 added five custom definitions on 2026-11-22 at
12:35Z (`claude-opus-5-5`, `claude-sonnet-5-5`, `claude-fable-5-2`, `claude-fable-5-1`,
`claude-haiku-5-5`), each pricing input, output, cache reads and the 5-minute and 1-hour cache
writes. Langfuse prices an observation when it is ingested, so the definitions apply only to traces
recorded after that time and the baseline is not re-priced. Use the price-weighted split of
§Totals instead: cache reads about 58 %, cache writes 28 %, output 14 %. The first cost figures
come with the first page taken after 2026-11-22T12:35Z.

## Caveats

- Floors are the minimum context seen, a proxy for the starting load, not a measurement of it.
- The subagent purpose split classifies descriptions by keyword; about 14 % are unclassified.
- The Bash split is a sample of 50 calls from one session.
- The analysis covers all projects; skillery shapes them through the installed bundles.
- Langfuse holds about a third fewer events than the transcripts and may repeat a long turn.
