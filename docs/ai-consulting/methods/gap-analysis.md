# Gap analysis

## What it is

Comparing where a client is today against its strategic ambition, to find what stands in the way.

## Owning flow

Gap analysis is owned, not a gap itself: it is step 3 of the Decision Package's discovery flow, in
[`skills/decision-package/references/discovery-flow.md` §3](../../../skills/decision-package/references/discovery-flow.md#3-gap-analysis).
That flow classifies each gap as blocking, sequenced, or out of scope, and the classification is
what shapes the recommendation and the roadmap. This page does not restate that table; it points to
it.

## Where it fits

Gap analysis is [`advisory-runbook.md`](../advisory-runbook.md)'s step 4, and it is the technique
[`consulting-dod.md`](../consulting-dod.md) names as the one method doc a future DoD could draw on
soonest, because it already has an owner.
