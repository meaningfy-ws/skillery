# Data maturity assessment

## What it is

A structured scoring of how well an organisation manages its data today: governance, quality,
stewardship, and cataloguing, each rated against a defined scale rather than judged by impression.

## Why it matters in a Deep-tier engagement

A scored baseline would sharpen the landscape-reading step of discovery (see
[`skills/decision-package/references/discovery-flow.md` §2](../../../skills/decision-package/references/discovery-flow.md#2-landscape--data-reading)):
instead of describing governance maturity in prose, the engagement could point to a specific score
and compare it against where the client's ambition requires it to be, which would make the gap
analysis that follows more precise.

[`skills/semantic-consulting-coach/references/semantic-consulting-domain.md`](../../../skills/semantic-consulting-coach/references/semantic-consulting-domain.md)).
Both name the activity; neither defines a rubric to score against.

## Where it would fit

If a scored rubric existed, [`advisory-runbook.md`](../advisory-runbook.md)'s step 2 (landscape
reading) would have a specific governance score to read instead of prose, and step 3 (method
selection) would gain a named option for engagements that need one. [`consulting-dod.md`](../consulting-dod.md)
would still need the rubric to exist before it could write a done-ness check for a scored
engagement.
